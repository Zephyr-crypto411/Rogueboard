# Rogueboard
A flipper app (.fap) that allows the user to sniff for and connect to E-skateboards via NRF24.

## ⚠️ Disclaimer

## What is it?
Rogueboard leverages an external NRF24L01 radio module to interact with 2.4 GHz electric skateboard speed controllers (ESCs)—such as LingYi and compatible chipsets. Designed for connectivity research, security testing, and signal analysis, it allows you to sniff connection handshakes, and send emulated control packets directly from your Flipper.

## How to use it:
Plug in NRF24 -> Start app ->Press Ok to scan-> list will populate with boards if any are found-> Use up and down to scroll through list -> use right button to pair.
